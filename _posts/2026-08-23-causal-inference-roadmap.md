> **이번 글의 목표:** “상관관계가 있다”와 “원인이다”가 왜 다른지 이해하고, 잠재적 결과와 평균처리효과(ATE)를 간단한 Python 실습으로 계산한다.

인과추론을 한 번도 공부하지 않았다고 가정하고 시작해 보자. 회귀분석이나 머신러닝 경험이 없어도 괜찮다. 평균의 뜻과 아주 간단한 Python 코드만 알면 이번 글을 따라갈 수 있다.

## 1. 인과추론은 어떤 질문에 답할까?

두 변수가 함께 움직이는지 묻는 것과, 한 변수를 직접 바꾸었을 때 다른 변수가 변하는지 묻는 것은 서로 다른 문제다.

- **상관 질문**: 공부 시간이 긴 학생은 시험 점수도 높은가?
- **인과 질문**: 같은 학생의 공부 시간을 1시간 늘리면 시험 점수가 얼마나 달라지는가?

첫 번째 질문은 관찰된 데이터의 패턴을 묻는다. 두 번째 질문은 아직 일어나지 않은 개입의 결과를 묻는다. 인과추론은 두 번째 질문에 답하기 위한 언어와 방법을 공부하는 분야다.

  <figcaption>그림 1. 함께 움직이는 것과 직접 바꾸었을 때 달라지는 것은 다른 질문이다.</figcaption>
</figure>

### 상관관계만으로 부족한 이유

공부 시간이 긴 학생의 점수가 높았다고 하자. 여기에는 여러 설명이 가능하다.

1. 공부 시간이 점수를 높였을 수 있다.
2. 원래 학습 의지가 높은 학생이 더 오래 공부하고 점수도 높았을 수 있다.
3. 좋은 수업이나 사교육처럼 관측하지 않은 다른 요인이 둘 모두에 영향을 주었을 수 있다.

관찰된 평균만으로는 이 설명들을 구분하기 어렵다. 특히 공부 시간과 점수 모두에 영향을 주는 세 번째 변수는 **교란 변수(confounder)**라고 부른다.

## 2. 인과 질문을 세 가지 기호로 바꾸기

인과추론에서는 먼저 질문을 다음 세 요소로 정리한다.

| 기호 | 이름 | 이번 글의 예시 |
| --- | --- | --- |
| $T$ | 처리 또는 개입 | 새로운 학습법 사용 여부 |
| $Y$ | 결과 | 시험 점수 |
| $X$ | 처리 이전의 특성 | 이전 시험 점수, 학습 시간 등 |

$T=1$은 새로운 학습법을 사용한 경우, $T=0$은 사용하지 않은 경우라고 하자. 우리가 알고 싶은 것은 단순히 두 집단의 점수가 다른지가 아니다.

> **같은 조건의 학생에게 새로운 학습법을 사용하게 했을 때, 사용하지 않았을 때보다 점수가 얼마나 달라지는가?**

이 문장에는 대상, 처리, 비교 대상, 결과가 모두 들어 있다. 인과 분석을 시작할 때는 모델보다 이 질문을 먼저 정확하게 쓰는 것이 중요하다.

## 3. 반사실: 일어나지 않은 결과를 생각하기

한 학생이 새로운 학습법을 사용해 82점을 받았다. 이 학생이 같은 시기에 그 학습법을 사용하지 않았다면 몇 점을 받았을까?

실제로 일어나지 않은 두 번째 결과를 **반사실(counterfactual)**이라고 한다. 인과효과는 현실에서 관측한 결과와 이 반사실을 비교하는 개념이다.

학생 $i$에게 가능한 두 결과를 다음처럼 쓴다.

$$
Y_i(1) = \text{새 학습법을 사용했을 때의 점수}
$$

$$
Y_i(0) = \text{새 학습법을 사용하지 않았을 때의 점수}
$$

두 값을 그 학생의 **잠재적 결과(potential outcomes)**라고 부른다. 개인별 인과효과는 두 잠재적 결과의 차이다.

$$
\tau_i = Y_i(1)-Y_i(0)
$$

  <figcaption>그림 2. 한 사람에게 가능한 결과는 두 개지만 현실에서 관측되는 결과는 하나뿐이다.</figcaption>
</figure>

### 인과추론의 근본적인 어려움

같은 학생이 같은 시점에 학습법을 사용하면서 동시에 사용하지 않을 수는 없다. 따라서 $Y_i(1)$과 $Y_i(0)$ 중 하나만 관측된다.

| 학생 | 실제 처리 | 관측한 결과 | 관측할 수 없는 반사실 |
| --- | ---: | ---: | ---: |
| A | $T=1$ | $Y_A(1)=82$ | $Y_A(0)=?$ |
| B | $T=0$ | $Y_B(0)=75$ | $Y_B(1)=?$ |

이처럼 개인의 인과효과를 직접 계산할 수 없는 문제를 **인과추론의 근본적 문제**라고 한다. 잠재적 결과 틀은 Rubin의 고전적 논문에서 체계적으로 정리되었으며, 현대 인과추론의 핵심 출발점이다.

## 4. 개인 대신 집단의 평균을 비교하기

개인의 두 결과를 동시에 볼 수 없다면 무엇을 할 수 있을까? 충분히 큰 집단의 평균 효과를 생각할 수 있다.

$$
ATE = E[Y(1)-Y(0)]
$$

ATE는 **평균처리효과(Average Treatment Effect)**다. 모든 사람에게 처리했을 때의 평균 결과와 아무에게도 처리하지 않았을 때의 평균 결과가 얼마나 다른지를 뜻한다.

예를 들어 ATE가 5점이라면 다음처럼 해석한다.

> 이 모집단에서 새로운 학습법은 시험 점수를 평균적으로 5점 높인다.

여기서 “평균적으로”라는 말이 중요하다. 모든 학생의 점수가 정확히 5점 오른다는 뜻은 아니다. 어떤 학생은 더 크게 오르고, 어떤 학생은 거의 변하지 않거나 낮아질 수도 있다.

## 5. 무작위배정은 왜 도움이 될까?

처리군과 대조군을 학생의 선택에 맡기면 원래 의지가 높은 학생이 새 학습법을 더 자주 선택할 수 있다. 그러면 두 집단의 점수 차이에는 학습법의 효과와 원래 의지의 차이가 섞인다.

반대로 동전 던지기처럼 무작위로 처리 여부를 정하면, 표본이 충분히 클 때 처리 전 특성들이 두 집단에 비슷하게 섞인다. 따라서 처리군과 대조군의 평균 차이는 ATE를 추정하는 자연스러운 방법이 된다.

<figure class="study-figure">
  <img src="{{ '/assets/images/causal-inference/randomized-experiment.svg' | relative_url }}" alt="참가자를 무작위로 처리군과 대조군에 배정한 뒤 두 집단의 평균 결과를 비교하는 실험 구조">
  <figcaption>그림 3. 무작위배정은 처리 이전 특성이 두 집단에 치우쳐 들어가는 것을 확률적으로 막아 준다.</figcaption>
</figure>

무작위실험에서 사용하는 가장 단순한 추정량은 다음과 같다.

$$
\widehat{ATE}
= \text{처리군의 결과 평균}
- \text{대조군의 결과 평균}
$$

표본이 작으면 우연히 차이가 생길 수 있으므로 추정값이 항상 정확히 참값과 같지는 않다. 그러나 무작위배정은 체계적인 선택 편향을 줄이고, 표본이 커질수록 평균 차이가 참 ATE에 가까워지게 한다.

## 6. 첫 Python 실습: 정답을 아는 가상 실험

이제 2,000명의 가상 학생을 만들고 새로운 학습법의 효과를 추정해 보자. 필요한 라이브러리는 `numpy` 하나뿐이다.

시뮬레이션에서는 우리가 데이터를 만드는 사람이므로 각 학생의 $Y(0)$과 $Y(1)$을 모두 알고 있다. 현실에서는 둘 중 하나만 관측된다는 차이를 기억하자.

```python
import numpy as np

rng = np.random.default_rng(42)
n = 2_000

# 새 학습법을 사용하지 않았을 때의 잠재적 점수 Y(0)
y0 = rng.normal(loc=70, scale=10, size=n)

# 학생마다 효과는 다르며, 평균 효과는 약 5점이다.
individual_effect = rng.normal(loc=5, scale=2, size=n)
y1 = y0 + individual_effect

# 동전 던지기처럼 절반의 확률로 처리군에 무작위배정한다.
treatment = rng.binomial(n=1, p=0.5, size=n)

# 현실에서 관측하는 결과: 각 학생의 잠재적 결과 중 하나만 선택된다.
observed = np.where(treatment == 1, y1, y0)

# 시뮬레이션이라서만 알 수 있는 실제 ATE
true_ate = np.mean(y1 - y0)

# 현실의 실험에서 계산할 수 있는 평균 차이 추정값
estimated_ate = (
    observed[treatment == 1].mean()
    - observed[treatment == 0].mean()
)

print(f"실제 ATE: {true_ate:.2f}")
print(f"추정한 ATE: {estimated_ate:.2f}")
print(f"처리군 학생 수: {treatment.sum()}")
```

실행 결과는 다음과 비슷하다.

```text
실제 ATE: 5.03
추정한 ATE: 5.37
처리군 학생 수: 972
```

### 결과를 한 줄씩 해석하기

1. `실제 ATE`는 두 잠재적 결과를 모두 알고 있는 시뮬레이션 속 정답이다.
2. `추정한 ATE`는 실제 데이터처럼 각 학생의 결과 하나만 사용해 계산했다.
3. 두 값의 차이 약 0.34점은 무작위 표본에서 생긴 우연한 오차다.
4. 코드를 다시 실행해도 seed를 `42`로 고정했기 때문에 같은 결과가 나온다.

이 실습의 핵심은 “두 평균을 빼면 언제나 인과효과다”가 아니다. **처리군과 대조군이 무작위배정으로 비교 가능하게 만들어졌기 때문에** 평균 차이를 인과효과로 해석할 수 있다는 점이다.

## 7. 직접 바꿔 보는 연습

### 연습 1: 표본 크기 바꾸기

`n = 100`, `n = 10_000`으로 각각 실행해 실제 ATE와 추정 ATE의 차이를 비교해 보자. 일반적으로 표본이 커지면 추정값의 흔들림이 작아진다.

### 연습 2: 평균 효과 바꾸기

`individual_effect`의 `loc=5`를 `loc=-3`으로 바꿔 보자. 실제 ATE와 추정 ATE가 모두 음수가 되는지 확인하고, 음의 효과가 무엇을 뜻하는지 문장으로 적어 본다.

### 연습 3: 여러 번 반복하기

seed를 `42`, `100`, `2026`으로 바꾸어 결과를 비교해 보자. 추정값은 매번 달라지지만 어느 값 주변에서 움직이는지 살펴본다.

## 8. 이번 글에서 꼭 기억할 다섯 문장

1. 상관관계는 두 변수가 함께 움직인다는 뜻이지, 하나가 다른 하나의 원인이라는 뜻은 아니다.
2. 인과 질문은 “처리를 했을 때”와 “하지 않았을 때”의 결과를 비교한다.
3. 한 사람에게 가능한 두 결과 $Y(1)$과 $Y(0)$을 잠재적 결과라고 한다.
4. 같은 사람의 두 잠재적 결과를 동시에 관측할 수 없으므로 집단의 평균 효과인 ATE를 추정한다.
5. 무작위배정은 처리군과 대조군을 비교 가능하게 만들어 단순 평균 차이를 인과적으로 해석할 근거를 제공한다.
