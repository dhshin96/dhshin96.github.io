> **이번 글의 목표:** 양의 확률성 가정을 식으로 설명하고, 성향점수가 0이나 1에 가까울 때 역확률 가중치가 커지는 과정을 손계산과 Python으로 확인한다.

결론부터 보자. 준비도가 높은 학생 100명 중 새 학습법을 쓰지 않은 학생이 단 1명이라면, 그 학생의 역확률 가중치는 **100**이다. 반면 같은 조건에서 학습법을 쓴 99명의 가중치는 약 **1.01**이다. 조정 공식은 계산되지만 대조군의 결과가 사실상 한 사람에게 의존한다.

앞 글에서 [DAG로 최소 충분 조정 집합을 고르는 법]({{ '/posts/causal-minimal-adjustment-set/' | relative_url }})을 배웠다. 그러나 올바른 변수로 조정해도 각 조건에서 비교할 처리군과 대조군이 없으면 인과효과를 자료로 식별할 수 없다. 이번에는 이 문제를 **양의 확률성(positivity)**과 **겹침(overlap)**이라는 두 표현으로 연결한다.

## 1. 같은 조건에서 두 선택지가 모두 보여야 한다

새 학습법 사용 여부를 $A$, 시험 점수를 $Y$, 처리 전에 측정한 준비도를 $L$이라고 하자. $L$로 조건화했을 때 교환가능성이 성립한다고 가정해도 다음 조건이 더 필요하다.

$$
0 < P(A=1\mid L=l) < 1
$$

목표 모집단에서 가능한 모든 $l$에 대해 학습법을 쓸 확률도, 쓰지 않을 확률도 0보다 커야 한다는 뜻이다. 그래야 같은 준비도 안에서 두 집단의 결과를 비교할 수 있다. 이 조건이 양의 확률성이다.

성향점수 $e(l)=P(A=1\mid L=l)$로 쓰면 처리 관측치의 역확률 가중치는 $1/e(l)$, 대조 관측치의 가중치는 $1/[1-e(l)]$이다.

$$
w_i=\frac{A_i}{e(L_i)}+\frac{1-A_i}{1-e(L_i)}
$$

$e(l)=1$이면 그 조건의 대조군은 존재하지 않고 분모 $1-e(l)$가 0이 된다. 이것은 표본을 더 모아도 처치 규칙상 대조군이 생기지 않는 **구조적 위반**일 수 있다. 확률이 0은 아니지만 0.01처럼 매우 작다면 계산은 가능해도 몇 명에게 큰 가중치가 몰리는 **실질적 위반**에 가깝다.

규정상 특정 준비도에서는 반드시 새 학습법을 써야 한다면, 그 조건의 대조 반사실은 현재 자료로 배울 수 없다. 반대로 두 학습법이 가능하지만 한쪽이 우연히 드물었다면 더 많은 자료가 겹침을 개선할 수 있다. 따라서 처리 할당이 실제로 가능한 범위를 먼저 확인한다.

양의 확률성은 조정변수의 선택과도 연결된다. 필요하지 않은 변수를 계속 추가해 조건을 지나치게 잘게 나누면, 원래 존재하던 비교 대상도 작은 셀로 흩어질 수 있다. 따라서 최소 충분 조정 집합은 편향 경로를 막으면서 불필요한 희소성을 줄이는 출발점이 된다. 다만 최소 집합이라고 해서 자동으로 겹침이 보장되는 것은 아니다.

## 2. 작은 손계산: 한 사람이 100명 몫이 되는 과정

준비도별로 100명씩 있고 결과 평균이 다음과 같다고 하자.

| 준비도 $L$ | 처리 $A$ | 인원 | 평균 점수 | $P(A=1\mid L)$ | 관측 처리의 가중치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 낮음(0) | 1 | 40 | 70 | 0.40 | $1/0.40=2.50$ |
| 낮음(0) | 0 | 60 | 65 | 0.40 | $1/0.60=1.67$ |
| 높음(1) | 1 | 99 | 85 | 0.99 | $1/0.99=1.01$ |
| 높음(1) | 0 | 1 | 75 | 0.99 | $1/0.01=100$ |

각 준비도 안의 평균 차이는 5점과 10점이다. 두 준비도 집단이 모집단에서 절반씩이므로 표준화한 ATE는 다음과 같다.

$$
(70-65)\times0.5+(85-75)\times0.5=7.5
$$

역확률 가중도 각 층을 처리별로 100명 규모처럼 복원해 같은 7.5점을 만든다. 문제는 답의 숫자보다 정보의 분포다. 준비도 높음·대조군 1명의 점수가 75가 아니라 65였다면 해당 층의 차이와 전체 ATE가 즉시 5점씩 달라진다. 큰 가중치는 소수 관측치의 측정오차와 우연한 변동까지 함께 증폭한다.

겹침이 충분한지는 표본 수만으로 판단할 수 없다. 준비도 범위별 처리 비율, 처리군과 대조군의 성향점수 분포, 가중치의 최솟값·최댓값을 함께 봐야 한다. 극단 가중치는 양의 확률성 부족뿐 아니라 성향점수 모형을 잘못 지정했을 때도 나타날 수 있으므로 원인을 구분해야 한다.

또한 “성향점수 0.05 이하면 항상 제거”처럼 하나의 숫자를 보편 규칙으로 삼을 수는 없다. 어느 범위를 제외할지 정하면 추정 대상도 함께 바뀐다. 전체 학생에게 적용할 ATE를 묻다가 두 학습법을 선택할 가능성이 충분한 학생에게만 적용되는 효과를 묻게 될 수 있다. 진단 뒤의 조치는 계산 편의보다 연구 질문과 목표 모집단을 먼저 적고 결정해야 한다.

## 3. Python 실습: ATE와 유효표본크기 계산하기

아래 코드는 표준 라이브러리만 사용해 200행 자료를 만들고, 정규화한 역확률 가중 평균과 가중치의 유효표본크기(ESS)를 계산한다.

```python
from math import fsum

cells = [
    # 준비도, 처리, 점수, 인원
    (0, 1, 70, 40),
    (0, 0, 65, 60),
    (1, 1, 85, 99),
    (1, 0, 75, 1),
]

rows = [
    {"l": level, "a": treatment, "y": score}
    for level, treatment, score, count in cells
    for _ in range(count)
]

propensity = {
    level: sum(r["a"] for r in rows if r["l"] == level)
    / sum(r["l"] == level for r in rows)
    for level in {0, 1}
}

for row in rows:
    e = propensity[row["l"]]
    row["w"] = 1 / e if row["a"] == 1 else 1 / (1 - e)


def weighted_mean(group):
    chosen = [r for r in rows if r["a"] == group]
    return fsum(r["w"] * r["y"] for r in chosen) / fsum(
        r["w"] for r in chosen
    )


def effective_sample_size(group):
    weights = [r["w"] for r in rows if r["a"] == group]
    return fsum(weights) ** 2 / fsum(w ** 2 for w in weights)


ate = weighted_mean(1) - weighted_mean(0)
print(f"성향점수: {propensity}")
print(f"가장 큰 가중치: {max(r['w'] for r in rows):.1f}")
print(f"IPW ATE: {ate:.1f}")
print(f"처리군 ESS: {effective_sample_size(1):.1f}")
print(f"대조군 ESS: {effective_sample_size(0):.1f}")
```

실행 결과는 다음과 같다.

```text
성향점수: {0: 0.4, 1: 0.99}
가장 큰 가중치: 100.0
IPW ATE: 7.5
처리군 ESS: 114.0
대조군 ESS: 3.9
```

### 결과 해석

실제 대조군은 61명이지만 가중치가 한 사람에게 몰려 ESS는 약 3.9명까지 줄었다. ESS는 새로운 관측치 수가 아니라, 가중치 불균형 때문에 정보량이 얼마나 감소했는지 보여 주는 진단값이다. ATE 7.5가 손계산과 일치한다는 사실만으로 안정적인 추정이 보장되지는 않는다.

이전의 [DAG 표준화 예제]({{ '/posts/causal-dag-confounding/' | relative_url }})에서는 각 준비도에 처리군과 대조군이 충분해 조정 전 17점을 5점으로 안정적으로 복원했다. 이번 자료는 같은 표준화 원리라도 한 셀에 관측치가 1개뿐이면 결과가 얼마나 취약해지는지 보여 준다.

## 4. 직접 바꿔 보는 연습

### 연습 1: 겹침을 회복하기

높은 준비도의 처리군과 대조군을 각각 50명으로 바꾼다. 최대 가중치가 2로, 두 집단 ESS가 실제 표본 수에 가까워지는지 확인한다.

### 연습 2: 구조적 위반 만들기

높은 준비도의 대조군 인원을 0으로 바꾼다. $e(1)=1$일 때 코드의 어느 분모가 0이 되는지 찾고, 자료에 없는 비교를 모형이 대신 만들어 낼 수 없는 이유를 설명한다.

### 연습 3: 목표 모집단 다시 생각하기

겹침이 있는 준비도 범위로 분석 대상을 제한하면 질문이 “전체 학생의 ATE”에서 무엇으로 바뀌는지 적는다. 관측치를 제외하거나 가중치를 절단하는 선택은 분산만 줄이는 기술이 아니라 목표 효과와 편향을 바꿀 수 있다.

## 5. 이번 글에서 꼭 기억할 다섯 문장

1. 양의 확률성은 모든 분석 조건에서 각 처리 수준을 받을 확률이 0보다 커야 한다는 식별 가정이다.
2. 겹침이 없으면 같은 조건의 처리군과 대조군을 자료로 비교할 수 없다.
3. 성향점수가 0이나 1에 가까우면 역확률 가중치가 커져 소수 관측치가 추정을 지배한다.
4. 극단 가중치와 낮은 ESS는 계산 성공과 추정 안정성이 다르다는 경고다.
5. 제한, 절단, 다른 목표 효과 선택은 자동 처방이 아니며 바뀐 대상과 가정을 명시해야 한다.
