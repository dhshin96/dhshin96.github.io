> **이번 글의 목표:** 두 입력을 받는 계산 단위의 가중합을 손으로 구하고, ReLU 활성화함수가 음수와 양수를 어떻게 처리하는지 Python 출력으로 확인한다.

입력 $(1,0)$에 가중치 $(2,-1)$과 편향 $-0.5$를 넣으면 가중합은 **1.5**다. ReLU를 통과한 출력도 **1.5**다. 같은 설정에서 입력 $(0,1)$의 가중합은 **-1.5**지만 출력은 **0**이다. 이 작은 차이를 직접 계산하면 신경망의 한 계산 단위가 무엇을 하는지 선명해진다.

이 글은 딥러닝 시리즈의 첫 단원이다. 블로그의 [학습과 모델링 글이 놓인 자리]({{ '/posts/welcome/' | relative_url }})를 먼저 보면 앞으로 이 시리즈가 어떤 기초를 쌓는지 알 수 있다. 이번에는 학습 알고리즘이나 복잡한 모델 구조를 건너뛰고, 입력에서 출력까지의 한 번의 계산에 집중한다.

## 1. 직관: 입력의 중요도를 정한 뒤 출력을 바꾼다

두 입력 $x_1,x_2$가 있다고 하자. 각 입력에 붙은 가중치 $w_1,w_2$는 해당 입력이 가중합에 얼마나 기여할지 정한다. 편향 $b$는 입력이 모두 0일 때도 가중합의 기준점을 옮긴다. 이 셋을 더한 값이 아직 최종 출력은 아니다. 마지막에 활성화함수 $f$가 값을 변환한다.

예제의 $w_1=2$는 첫 입력이 1 늘면 가중합이 2 늘어난다는 뜻이고, $w_2=-1$은 둘째 입력이 1 늘면 가중합이 1 줄어든다는 뜻이다. 편향 $-0.5$를 넣었으므로 입력이 모두 0이면 가중합은 $-0.5$다. 가중치와 편향은 여기서 **설명용으로 고정한 숫자**다. 데이터를 학습시켜 얻은 값이 아니다.

이 글에서는 이런 가중합 계산 단위를 퍼셉트론의 기본 형태로 부른다. 역사적 의미의 단층 퍼셉트론은 계단함수로 두 부류를 가르는 모델이며, 여기서는 신경망의 노드 계산을 이해하기 위해 ReLU를 붙인다. 두 개념을 같은 학습 알고리즘으로 혼동하지 말자.

## 2. 기호와 수식: 가중합 $z$에서 출력 $a$까지

입력과 가중치를 각각 $\boldsymbol{x}=(x_1,x_2)$, $\boldsymbol{w}=(w_1,w_2)$로 적으면 계산은 다음 두 단계다.

$$
z=w_1x_1+w_2x_2+b,\qquad a=f(z)
$$

이번 글의 활성화함수는 ReLU(rectified linear unit)다. 음수는 0으로 만들고, 0과 양수는 그대로 둔다.

$$
\operatorname{ReLU}(z)=\max(0,z)
$$

가중합 $z$와 활성화 뒤 출력 $a$를 구별해야 한다. 입력이 같아도 함수가 무엇인지에 따라 최종 출력은 달라진다. ReLU의 출력은 항상 0 이상이지만, **0이 곧 특정 부류의 예측이라는 뜻은 아니다**. 분류 여부는 모델의 출력 설계와 학습 목적까지 알아야 판단할 수 있다.

## 3. 작은 손계산: 네 입력을 모두 대입해 보자

$w_1=2,w_2=-1,b=-0.5$를 고정하고 입력을 $(0,0)$, $(0,1)$, $(1,0)$, $(1,1)$로 바꾼다.

| 입력 $(x_1,x_2)$ | 가중합 $z=2x_1-x_2-0.5$ | ReLU 출력 $a$ |
| --- | ---: | ---: |
| $(0,0)$ | $-0.5$ | $0$ |
| $(0,1)$ | $-1.5$ | $0$ |
| $(1,0)$ | $1.5$ | $1.5$ |
| $(1,1)$ | $0.5$ | $0.5$ |

예를 들어 $(1,1)$은 $2\times1-1\times1-0.5=0.5$다. 첫 입력이 1인 두 행의 출력이 다르다. 둘째 입력의 음수 가중치가 가중합을 낮추기 때문이다. 아래 그림은 $(1,0)$과 $(0,1)$ 두 경우의 계산을 같은 숫자로 보여 준다.

## 4. 실행 가능한 Python 실습

다음 코드는 외부 패키지 없이 Python 표준 기능만 쓴다. 가중합과 활성화함수를 별도 함수로 두면 어느 단계에서 값이 달라졌는지 확인하기 쉽다.

```python
def weighted_sum(x1, x2, w1=2.0, w2=-1.0, bias=-0.5):
    return w1 * x1 + w2 * x2 + bias


def relu(z):
    return max(0.0, z)


for x1, x2 in [(0, 0), (0, 1), (1, 0), (1, 1)]:
    z = weighted_sum(x1, x2)
    print(f"({x1},{x2}): z={z:.1f}, ReLU={relu(z):.1f}")

print("두 ReLU의 합")
for x in [-2, -1, 0, 1, 2]:
    y = relu(x) + relu(-x)
    print(f"x={x:+d}, y={y:.1f}")
```

실행 출력은 다음과 같다.

```text
(0,0): z=-0.5, ReLU=0.0
(0,1): z=-1.5, ReLU=0.0
(1,0): z=1.5, ReLU=1.5
(1,1): z=0.5, ReLU=0.5
두 ReLU의 합
x=-2, y=2.0
x=-1, y=1.0
x=+0, y=0.0
x=+1, y=1.0
x=+2, y=2.0
```

## 5. 결과 해석: 왜 활성화함수를 끼워 넣을까?

첫 네 줄은 손계산 표와 정확히 일치한다. `weighted_sum`은 음수도 그대로 반환하지만 `relu`는 음수를 0으로 바꾼다. 둘째 실험에서 $\operatorname{ReLU}(x)+\operatorname{ReLU}(-x)$는 $|x|$가 된다. $x=-2$라면 첫 항은 0, 둘째 항은 2다. $x=2$라면 반대다. 두 직선 형태의 계산을 조합했는데 가운데에서 방향이 꺾이는 출력을 얻었다.

가중합만 여러 층 쌓으면 결국 또 하나의 가중합으로 합칠 수 있다. 예를 들어 $h=2x+1$, $y=3h-4$라면 $y=6x-1$이다. 층이 늘어도 이 관계는 직선이다. 활성화함수가 중간에 들어가면 입력 구간에 따라 계산이 달라진다. 그래서 여러 노드를 결합해 직선 하나로 표현하기 어려운 관계를 만들 수 있다. 다만 **이번 코드는 고정한 숫자로 출력을 계산했을 뿐, 학습하거나 성능을 검증한 실험은 아니다**.

## 6. 직접 바꿔 보는 연습

먼저 `bias=-0.5`를 `bias=0.5`로 바꾸고 네 입력을 다시 계산해 보자. $(0,0)$의 가중합은 $0.5$가 되어 ReLU 출력도 $0.5$로 달라진다. 다른 행도 모두 가중합이 1씩 늘지만, ReLU 출력의 변화량은 행마다 같지 않을 수 있다. 음수 구간에서는 여전히 0에 머물기 때문이다.

그다음 `w2=-1.0`을 `w2=1.0`으로 바꾸고 $(0,1)$과 $(1,1)$을 비교해 보자. 둘째 입력의 기여 방향이 뒤집히므로 두 행의 가중합이 각각 2씩 늘어난다. 계산 전 예상값을 적고 출력과 대조하면 가중치의 역할을 쉽게 구분할 수 있다.

마지막으로 두 ReLU의 합에서 `relu(-x)`를 지워 보자. 음수 입력에 대해 출력이 모두 0으로 바뀐다. 두 번째 노드가 음수 쪽 구간을 담당했다는 사실을 확인할 수 있다. 이 실험은 비선형 계산을 만드는 과정이지, 어느 함수를 모든 문제에 써야 하는지 결정하는 규칙은 아니다.

## 핵심 요약

- 한 계산 단위는 입력에 가중치를 곱해 더하고 편향을 더해 $z$를 만든다.
- ReLU는 $a=\max(0,z)$를 출력한다. 가중합과 활성화 뒤 출력은 구별해야 한다.
- 중간에 비선형 활성화함수를 넣으면 가중합만 쌓을 때와 달리 구간에 따라 달라지는 관계를 표현할 수 있다.

예측 계산과 원인에 대한 질문은 구별해서 읽어야 한다. [상관관계와 인과관계의 차이를 설명한 글]({{ '/posts/causal-inference-roadmap/' | relative_url }})은 신경망 출력이 어떤 패턴을 나타내더라도 그것만으로 원인과 결과를 말할 수 없는 이유를 이해하는 데 도움이 된다.
