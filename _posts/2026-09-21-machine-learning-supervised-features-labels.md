> **이번 글의 목표:** 지도학습의 한 행을 특성 $x$와 레이블 $y$로 나누고, 같은 입력으로도 숫자를 예측할지 범주를 예측할지에 따라 회귀와 분류 문제가 달라짐을 확인한다.

아래 합성 자료에서 공부 시간 1·2·3·4시간에 대응하는 점수는 40·50·60·70점이다. 가장 가까운 기존 시간을 참고하는 간단한 규칙으로 **2.6시간의 점수를 60점**, 60점 이상을 통과로 정한 문제에서는 **통과**라고 예측한다. 두 답을 만드는 입력은 같지만 정답의 뜻은 다르다. 이 글은 모델 성능을 겨루기 전에 무엇을 입력하고 무엇을 맞힐지 정하는 연습이다.

머신러닝 글이 놓인 위치가 궁금하다면 [블로그의 기반 지식과 학습·모델링 소개]({{ '/posts/welcome/' | relative_url }})를 먼저 보면 된다. 이번 글은 그중 지도학습의 첫 단원이다.

## 1. 직관: 한 행에서 무엇을 가리고 맞힐까

지도학습은 **정답이 붙은 예제**로 입력과 정답의 관계를 배우고, 새 입력의 정답을 예측한다. 한 행을 ‘공부 시간 2시간, 점수 50점’으로 적었다면, 공부 시간은 예측할 때 제공하는 **특성(feature)**이고 점수는 맞히려는 **레이블(label)**이다. 특성은 여러 개일 수도 있고 레이블을 목표값 또는 타깃이라고도 부른다.

문제를 정의할 때는 “어떤 자료가 있나”보다 “새 행에서 실제로 어떤 값을 알아야 하나”를 먼저 적는다. 새 행의 점수를 알고 싶으면 레이블은 점수다. 통과 여부를 알고 싶으면 레이블은 통과·미통과다. 점수라는 숫자를 60점 기준으로 바꾼 통과 여부는 이 예제를 설명하기 위해 만든 별도 정답이다. 예측 시점에 이미 알고 있는 특성만 입력으로 써야 한다. 새 행의 실제 점수를 입력에 넣고 통과 여부를 맞히면, 답을 미리 보여 준 셈이다.

## 2. 기호와 수식: 입력 $x$에서 정답 $y$로

예제 $i$를 $(x_i,y_i)$로 적는다. 이 글에서 $x_i$는 공부 시간이고, 회귀 문제의 $y_i$는 점수다. 학습된 규칙 $f$는 새 입력 $x_{\mathrm{new}}$에 대해 예측값 $\hat y=f(x_{\mathrm{new}})$를 낸다. 모자 표시가 붙은 $\hat y$는 관측된 정답 $y$와 구별한다.

**회귀(regression)**는 40점, 50점처럼 수치값을 예측하는 문제다. **분류(classification)**는 미통과와 통과처럼 미리 정한 범주를 예측하는 문제다. 예제에서 분류 레이블은 다음처럼 만든다.

$$
y_i^{\mathrm{class}}=
\begin{cases}
\text{통과}, & y_i^{\mathrm{score}}\ge 60,\\
\text{미통과}, & y_i^{\mathrm{score}}<60.
\end{cases}
$$

여기서 60점은 **예제를 위한 정의**이며 외부 자료의 합격 기준이 아니다. 숫자로 적힌 범주 코드가 있다고 해서 모두 회귀가 되는 것도 아니다. 답이 연속적인 양인지, 서로 다른 이름의 범주인지가 문제 종류를 가른다.

## 3. 작은 손계산: 같은 표에서 두 정답 만들기

| 공부 시간 $x$ | 점수 레이블 | 통과 레이블 |
| ---: | ---: | :--- |
| 1시간 | 40점 | 미통과 |
| 2시간 | 50점 | 미통과 |
| 3시간 | 60점 | 통과 |
| 4시간 | 70점 | 통과 |

새 입력 2.6시간과 기존 시간 사이의 거리는 각각 1.6, 0.6, 0.4, 1.4시간이다. 가장 가까운 행은 3시간이므로 그 행의 점수 60점과 범주 통과를 가져온다. 이는 가장 가까운 예제 하나를 쓰는 **설명용 규칙**이다. 네 행에서 잘 맞는다고 새로운 시간에서도 정확하다는 뜻은 아니다.

## 4. 실행 가능한 Python 실습

외부 패키지 없이 네 행을 만들고, 새 입력과의 거리가 가장 짧은 행을 고른다. `min`이 반환한 행의 **특성**으로 거리를 계산하며 실제 새 점수는 사용하지 않는다. 범주 레이블은 점수에서 만들지만, 예측할 때는 새 입력의 점수를 알지 못한다.

```python
hours = [1, 2, 3, 4]
scores = [40, 50, 60, 70]
rows = [(x, score, "통과" if score >= 60 else "미통과")
        for x, score in zip(hours, scores)]

new_hours = 2.6
closest = min(rows, key=lambda row: abs(row[0] - new_hours))

print("학습 예제 수:", len(rows))
print("가장 가까운 시간:", closest[0])
print("회귀 예측:", closest[1], "점")
print("분류 예측:", closest[2])
```

실행 출력은 다음과 같다.

```text
학습 예제 수: 4
가장 가까운 시간: 3
회귀 예측: 60 점
분류 예측: 통과
```

## 5. 결과 해석: 예측값과 실력을 구분하기

출력의 60점은 2.6시간을 실제로 관측한 점수가 아니다. 가장 가까운 **기존 행의 레이블을 복사한 예측값**이다. 통과도 해당 행에 붙여 둔 범주를 가져온 결과다. 이 코드는 입력과 정답을 나눠 생각하기 위한 최소한의 학습 규칙이며, 어떤 학습법이 가장 좋은지 판단하는 실험은 아니다.

새 행의 실제 정답이 있어야 예측과 비교할 수 있다. 학습에 사용한 네 행을 그대로 다시 맞혀 보고 “정확하다”고 말하면 새 자료에 대한 성능을 알 수 없다. 다음 단원에서 학습·검증·테스트를 나누는 이유가 여기 있다. 시간 순서가 있는 자료라면 무작위 분할이 위험할 수 있다는 점은 [시계열의 시간 순서 분할 실습]({{ '/posts/time-series-components-chronological-split/' | relative_url }})에서 먼저 볼 수 있다.

같은 입력에서 다른 출력을 만드는 계산 구조가 궁금하다면 [퍼셉트론의 입력과 출력 손계산]({{ '/posts/deep-learning-perceptron-relu/' | relative_url }})도 도움이 된다. 그 글의 가중치는 설명용 고정값이고, 이 글의 가장 가까운 행 규칙과는 다른 계산이다.

## 핵심 요약

- 지도학습의 한 예제는 예측에 쓰는 특성 $x$와 맞힐 레이블 $y$의 쌍이다.
- 수치값을 맞히는 회귀와 범주를 맞히는 분류는 같은 입력에서도 레이블 정의에 따라 갈린다.
- 예측값 하나를 얻은 것과 새 자료에서의 성능을 검증한 것은 다르다.
