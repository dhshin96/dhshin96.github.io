> **이번 글의 목표:** 회귀의 평균제곱오차(MSE)와 이진 분류의 교차엔트로피를 손으로 계산하고, 예제별 손실을 평균내는 과정을 Python 출력으로 확인한다.

세 회귀 예제의 정답이 $(3,-1,2)$, 예측이 $(2.5,0,2)$라면 제곱오차는 $(0.25,1,0)$이고 MSE는 **0.4167**이다. 세 이진 분류 예제에서 정답 클래스에 준 확률이 $(0.9,0.8,0.8)$이면 교차엔트로피는 **0.1839**다. 손실함수는 서로 다른 예측을 이렇게 비교 가능한 하나의 수로 바꾼다.

앞 글에서 만든 가중합과 ReLU 출력은 아직 학습의 방향을 알려 주지 않는다. [퍼셉트론과 ReLU 계산을 먼저 확인하면]({{ '/posts/deep-learning-perceptron-relu/' | relative_url }}) 이번 글의 예측값이 어디서 나오는지 연결해서 볼 수 있다. 이번에는 가중치 변경이나 역전파로 넘어가기 전에, **예측이 얼마나 틀렸는지 재는 규칙**에만 집중한다.

## 1. 직관: 채점 규칙이 있어야 예측을 비교할 수 있다

모델은 숫자를 출력한다. 회귀 모델은 온도처럼 연속적인 값을 내놓고, 이진 분류 모델은 한 클래스일 확률을 내놓을 수 있다. 정답과 예측만 나열해서는 여러 예제를 한꺼번에 비교하기 어렵다. 손실함수는 예측과 정답을 받아 작은 값일수록 더 잘 맞도록 설계한 채점 규칙이다.

손실은 정확도와 같은 평가 지표와 역할이 다르다. 예를 들어 정답이 1일 때 확률 0.51과 0.99는 임계값 0.5에서 모두 맞은 분류지만, 교차엔트로피는 0.99에 더 작은 손실을 준다. 학습 과정은 이런 연속적인 차이를 이용해 매개변수를 어느 방향으로 바꿀지 찾는다. 다만 손실값은 함수와 축약 방식에 따라 척도가 달라지므로, 서로 다른 손실의 숫자 크기만 직접 비교해서 모델의 우열을 정하면 안 된다.

회귀와 분류가 아직 낯설다면 [특성·레이블과 회귀·분류를 구분한 글]({{ '/posts/machine-learning-supervised-features-labels/' | relative_url }})이 어떤 출력에 어떤 손실을 연결하는지 이해하는 데 도움이 된다.

## 2. 기호와 수식: 예제별 손실을 평균으로 모은다

예제가 $N$개이고 $i$번째 정답과 예측을 각각 $y_i$, $\hat{y}_i$라고 하자. 회귀에서 자주 쓰는 평균제곱오차는 차이를 제곱한 뒤 평균낸다.

$$
\operatorname{MSE}=\frac{1}{N}\sum_{i=1}^{N}(y_i-\hat{y}_i)^2
$$

제곱하기 때문에 부호가 사라지고, 오차 2는 오차 1보다 두 배가 아니라 네 배의 손실을 만든다. 큰 오차를 더 강하게 반영하는 성질이다.

이진 분류에서 $y_i\in\{0,1\}$이고 모델이 클래스 1의 확률 $p_i$를 출력한다고 하자. 이진 교차엔트로피는 다음과 같다.

$$
\operatorname{BCE}=-\frac{1}{N}\sum_{i=1}^{N}\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right]
$$

정답이 1이면 $-\log p_i$, 정답이 0이면 $-\log(1-p_i)$만 남는다. 즉 모델이 **정답 클래스에 준 확률**의 음의 로그를 계산한다. 정답 확률이 1에 가까우면 손실은 0에 가까워지고, 0에 가까우면 손실은 빠르게 커진다.

## 3. 작은 손계산: 같은 세 예제를 한 값으로 모으기

먼저 회귀 예제 세 개를 계산한다.

| 예제 | 정답 $y$ | 예측 $\hat{y}$ | 제곱오차 $(y-\hat{y})^2$ |
| --- | ---: | ---: | ---: |
| 1 | 3.0 | 2.5 | 0.25 |
| 2 | -1.0 | 0.0 | 1.00 |
| 3 | 2.0 | 2.0 | 0.00 |

따라서 $\operatorname{MSE}=(0.25+1+0)/3=0.4166\ldots$이고, 소수 넷째 자리까지 쓰면 0.4167이다.

이진 분류에서는 정답이 $(1,0,1)$이고 클래스 1의 예측 확률이 $(0.9,0.2,0.8)$이라고 하자. 정답 클래스의 확률은 각각 $(0.9,0.8,0.8)$이다. 예제별 손실은 $(-\log0.9,-\log0.8,-\log0.8)\approx(0.1054,0.2231,0.2231)$이다. 평균은 0.1839다.

## 4. 실행 가능한 Python 실습

다음 코드는 표준 라이브러리의 `math.log`만 사용한다. 두 함수를 따로 두어 예제별 손실과 평균 손실을 모두 확인한다.

```python
import math


def mean_squared_error(targets, predictions):
    losses = [(y - y_hat) ** 2 for y, y_hat in zip(targets, predictions)]
    return losses, sum(losses) / len(losses)


def binary_cross_entropy(labels, probabilities):
    losses = [
        -(y * math.log(p) + (1 - y) * math.log(1 - p))
        for y, p in zip(labels, probabilities)
    ]
    return losses, sum(losses) / len(losses)


mse_items, mse = mean_squared_error([3.0, -1.0, 2.0], [2.5, 0.0, 2.0])
bce_items, bce = binary_cross_entropy([1, 0, 1], [0.9, 0.2, 0.8])
_, uncertain_bce = binary_cross_entropy([1, 0, 1], [0.6, 0.4, 0.55])

print("제곱오차:", [round(value, 4) for value in mse_items])
print(f"MSE: {mse:.4f}")
print("교차엔트로피:", [round(value, 4) for value in bce_items])
print(f"BCE: {bce:.4f}")
print(f"덜 확신한 예측의 BCE: {uncertain_bce:.4f}")
```

실행 출력은 다음과 같다.

```text
제곱오차: [0.25, 1.0, 0.0]
MSE: 0.4167
교차엔트로피: [0.1054, 0.2231, 0.2231]
BCE: 0.1839
덜 확신한 예측의 BCE: 0.5398
```

## 5. 결과 해석: 작은 손실이 뜻하는 것

MSE 출력은 손계산과 같다. 두 번째 예제의 오차 크기는 1이고 첫 번째는 0.5이므로, 제곱 뒤에는 각각 1과 0.25가 된다. 평균 손실 0.4167 가운데 대부분을 두 번째 예제가 차지한다. 어느 예제가 전체 손실을 키우는지 보려면 평균만 보지 말고 예제별 손실도 함께 확인해야 한다.

교차엔트로피의 첫 예측은 정답 클래스에 0.8 이상을 주었다. 반면 두 번째 확률 묶음 $(0.6,0.4,0.55)$은 세 정답을 모두 맞히지만 정답 쪽 확신이 약하다. 그래서 BCE가 0.1839에서 0.5398로 커진다. 교차엔트로피는 맞았는지뿐 아니라 정답에 얼마의 확률을 주었는지 반영한다.

여기서 손실이 작다는 말은 **현재 데이터와 현재 손실함수 아래에서** 예측이 정답에 더 가깝다는 뜻이다. 새 데이터에서도 잘 맞는다는 보장은 아니다. [학습·검증·테스트 데이터를 나누는 이유]({{ '/posts/machine-learning-train-validation-test-split/' | relative_url }})를 함께 보면 학습 손실과 일반화 성능을 구별할 수 있다.

## 6. 직접 바꿔 보는 연습

회귀 예측의 두 번째 값 `0.0`을 `-0.5`로 바꿔 보자. 그 예제의 제곱오차는 1에서 0.25로 줄고 MSE는 $(0.25+0.25+0)/3=0.1667$이 된다. 계산 전에 결과를 예상한 뒤 실행값과 비교한다.

분류 확률의 첫 값을 `0.9`에서 `0.99`로 바꾸면 정답 클래스에 더 큰 확률을 주므로 첫 예제 손실이 줄어든다. 반대로 `0.1`로 바꾸면 손실은 크게 늘어난다. 단, 코드에 정확히 0이나 1을 넣으면 `log(0)`을 계산할 수 없다. 실제 라이브러리는 보통 로짓을 직접 받는 수치적으로 안정적인 함수를 제공하므로 API가 기대하는 입력을 확인해야 한다.

마지막으로 평균 대신 합을 출력해 보자. 데이터 개수가 두 배가 되면 합은 대체로 커지지만 평균은 예제당 손실 척도를 유지한다. 어떤 축약을 사용했는지 기록해야 실험 사이 숫자를 올바르게 비교할 수 있다.

## 핵심 요약

- 손실함수는 예측과 정답의 차이를 학습에 사용할 하나의 수로 만든다.
- MSE는 회귀 오차를 제곱해 평균내므로 큰 오차를 더 강하게 반영한다.
- 이진 교차엔트로피는 정답 클래스에 준 확률의 음의 로그를 평균내며, 맞은 예측 사이의 확신 차이도 구분한다.
- 평균 손실만 보지 말고 예제별 손실, 데이터 분할, 함수의 입력 형식을 함께 확인해야 한다.
