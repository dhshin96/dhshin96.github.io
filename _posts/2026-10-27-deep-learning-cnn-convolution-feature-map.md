> **이번 글의 목표:** CNN의 합성곱 필터가 한 위치의 값을 계산하는 법과, 같은 필터를 모든 위치에 공유해 특징 맵을 만드는 원리를 설명한다.

4×4 입력에 2×2 필터를 한 칸씩 옮겨 적용한 결과는 아래 3×3 특징 맵이다. 가운데 열의 **4, 5, 6**이 크다. 입력의 왼쪽 값보다 오른쪽 값이 커지는 세로 경계를 필터가 같은 계산으로 세 번 찾아낸 결과다.

```text
입력 X             필터 K          특징 맵 Y
1 1 3 3            -1  1           0 4 0
1 1 3 3            -1  1           0 5 0
2 2 5 5                              0 6 0
2 2 5 5
```

앞 글에서는 [가중치 감쇠와 드롭아웃이 과적합을 줄이는 위치]({{ '/posts/deep-learning-weight-decay-dropout/' | relative_url }})를 구분했다. 이제 이미지의 가로·세로 배치를 유지하면서 작은 지역 패턴을 찾는 합성곱 신경망(CNN)으로 넘어간다.

## 1. 직관: 작은 창 하나를 여러 위치에서 다시 쓴다

이미지를 한 줄로 펼치면 서로 이웃하던 픽셀의 관계를 따로 기억해야 한다. CNN의 합성곱 층은 입력 전체를 한꺼번에 보지 않고, 필터 또는 커널이라 부르는 작은 숫자 격자를 지역 영역에 겹친다. 겹친 숫자끼리 곱한 뒤 모두 더하면 출력 한 칸이 된다.

필터는 오른쪽과 아래로 이동하지만 숫자는 바뀌지 않는다. 이를 **가중치 공유**라고 한다. 위 예제에서 출력 위치는 9개지만 학습할 필터 가중치는 4개뿐이다. 각 위치마다 별도 2×2 가중치를 쓴다면 36개가 필요하다. 같은 패턴을 어디서든 같은 기준으로 검사하면서 매개변수도 줄이는 구조다.

필터 하나가 모든 위치를 훑어 만든 2차원 출력을 특징 맵이라 한다. 실제 CNN에서는 여러 필터를 학습해 여러 특징 맵을 만들고, 다음 층이 이를 다시 입력으로 받는다. 필터 숫자는 사람이 경계 검출값으로 고정하는 대신 [역전파가 계산한 기울기]({{ '/posts/deep-learning-backpropagation-chain-rule/' | relative_url }})로 갱신할 수 있다.

## 2. 기호와 수식: 합성곱 층이 실제로 하는 계산

입력을 $X$, 높이 $k_h$·너비 $k_w$인 필터를 $K$, 편향을 $b$라 하자. 출력의 $(i,j)$ 위치는 다음처럼 계산한다.

$$
Y_{i,j}=b+\sum_{a=0}^{k_h-1}\sum_{c=0}^{k_w-1}X_{i+a,j+c}K_{a,c}
$$

딥러닝 라이브러리가 보통 구현하는 연산은 필터를 뒤집지 않는 **교차상관**이다. 관례상 이 층을 합성곱 층이라고 부른다. 핵심은 어느 출력 위치에서도 같은 $K$를 사용한다는 점이다.

패딩이 0이고 보폭이 1이면, 높이 $n_h$·너비 $n_w$ 입력의 출력 크기는 다음과 같다.

$$
(n_h-k_h+1)\times(n_w-k_w+1)
$$

따라서 4×4 입력에 2×2 필터를 적용하면 $(4-2+1)\times(4-2+1)=3\times3$이 된다. 보폭은 필터가 한 번에 움직이는 칸 수이고, 패딩은 가장자리 둘레에 값을 덧붙이는 방법이다. 이번 실습에서는 계산의 핵심을 보기 위해 보폭 1, 패딩 0만 사용한다.

## 3. 작은 손계산: 특징 맵의 4는 어디서 왔을까

필터 $K$는 왼쪽 열에 -1, 오른쪽 열에 1을 둔다. 입력의 첫 위치에서는 다음 계산으로 0이 나온다.

$$
1(-1)+1(1)+1(-1)+1(1)=0
$$

필터를 오른쪽으로 한 칸 옮기면 입력 조각이 $\begin{bmatrix}1&3\\1&3\end{bmatrix}$으로 바뀐다.

$$
1(-1)+3(1)+1(-1)+3(1)=4
$$

왼쪽과 오른쪽의 차이가 클수록 양의 반응이 커진다. 아래 행에서도 같은 필터를 적용하므로 경계의 변화량에 따라 5와 6이 나온다. 필터가 경계의 의미를 이해한 것은 아니다. 같은 지역 내적이 특정 숫자 배열에 크게 반응한 것이다.

## 4. 실행 가능한 Python 실습

다음 코드는 외부 패키지 없이 2차원 교차상관을 구현한다. 출력 크기를 먼저 계산하고, 각 위치에서 입력 조각과 필터의 원소별 곱을 더한다.

```python
def cross_correlation_2d(x, kernel):
    input_h, input_w = len(x), len(x[0])
    kernel_h, kernel_w = len(kernel), len(kernel[0])
    output_h = input_h - kernel_h + 1
    output_w = input_w - kernel_w + 1

    output = []
    for i in range(output_h):
        row = []
        for j in range(output_w):
            value = 0
            for a in range(kernel_h):
                for c in range(kernel_w):
                    value += x[i + a][j + c] * kernel[a][c]
            row.append(value)
        output.append(row)
    return output

x = [
    [1, 1, 3, 3],
    [1, 1, 3, 3],
    [2, 2, 5, 5],
    [2, 2, 5, 5],
]
kernel = [
    [-1, 1],
    [-1, 1],
]

feature_map = cross_correlation_2d(x, kernel)
print(f"output shape: {len(feature_map)} x {len(feature_map[0])}")
for row in feature_map:
    print(row)
print("shared weights:", sum(len(row) for row in kernel))
print("unshared local weights:", 9 * 4)
```

실행 출력은 다음과 같다.

```text
output shape: 3 x 3
[0, 4, 0]
[0, 5, 0]
[0, 6, 0]
shared weights: 4
unshared local weights: 36
```

## 5. 결과 해석: 큰 값은 필터와 닮은 지역이다

특징 맵의 가운데 열만 양수인 이유는 그 위치의 입력 조각에서 오른쪽 열이 왼쪽 열보다 크기 때문이다. 첫째 행에서 차이는 두 줄에 걸쳐 각각 2이므로 합이 4다. 그 아래 창에는 값의 변화가 함께 들어가 5가 되고, 마지막 창에서는 차이 합이 6이 된다.

출력 위치가 늘어나도 필터의 네 가중치를 공유한다. 이 네 값이 학습되면 한 필터는 특정 방향의 밝기 변화나 반복되는 지역 모양에 반응할 수 있다. 여러 필터가 만든 특징 맵에 [ReLU 활성화함수]({{ '/posts/deep-learning-perceptron-relu/' | relative_url }})를 적용하면 음수 반응을 0으로 바꾸고, 다음 합성곱 층이 앞 층의 지역 특징을 다시 조합한다.

다만 특징 맵의 큰 값만 보고 사람이 정한 의미를 단정하면 안 된다. 학습된 필터의 반응은 데이터, 손실함수, 다른 층과 함께 결정된다. 이번 고정 필터는 계산 원리를 분리해서 보기 위한 예제다.

## 6. 직접 바꿔 보는 연습

먼저 필터를 `[[1, -1], [1, -1]]`로 바꿔 특징 맵의 부호가 뒤집히는지 확인한다. 다음으로 입력의 오른쪽 두 열을 모두 1로 바꿔 경계가 사라지면 출력이 어떻게 되는지 계산한다.

마지막으로 5×5 입력과 3×3 필터를 만들고 출력 크기를 코드 실행 전에 손으로 예측한다. 필터 크기는 9개인데 출력 위치마다 별도 가중치를 두면 몇 개가 필요한지도 비교해 본다.

## 핵심 요약

- 합성곱 층은 작은 필터와 지역 입력을 원소별로 곱해 더하고, 그 결과를 특징 맵의 한 칸에 기록한다.
- 같은 필터를 모든 위치에 공유하므로 같은 지역 패턴을 반복해서 검사하면서 매개변수 수를 줄인다.
- 패딩 0, 보폭 1일 때 출력 크기는 입력 크기에서 필터 크기를 뺀 뒤 1을 더해 구한다.
- 딥러닝의 합성곱 층은 보통 필터를 뒤집지 않는 교차상관을 계산하며, 필터 값은 역전파로 학습할 수 있다.
