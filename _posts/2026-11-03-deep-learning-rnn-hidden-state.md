> **이번 글의 목표:** 기본 순환 신경망(RNN)의 은닉 상태가 이전 정보를 다음 시점으로 전달하는 계산을 설명하고, 입력 순서가 최종 상태를 바꾸는 이유를 확인한다.

입력 `1, 0, 1`을 차례로 넣었더니 은닉 상태는 **0.7616 → 0.3634 → 0.8280**으로 변했다. 둘째 입력이 0이어도 상태가 0으로 사라지지 않는다. 첫 입력의 흔적이 이전 은닉 상태를 통해 남았기 때문이다.

앞 글에서는 [CNN이 같은 필터를 여러 위치에 공유하는 계산]({{ '/posts/deep-learning-cnn-convolution-feature-map/' | relative_url }})을 살펴봤다. RNN도 같은 가중치를 공유하지만, 공간의 여러 위치가 아니라 **시간의 여러 시점**에 반복해서 쓴다.

## 1. 직관: 한 칸짜리 메모장을 다음 시점에 넘긴다

문장, 소리, 센서값처럼 순서가 있는 데이터에서는 현재 값만으로 충분하지 않을 때가 많다. RNN은 시점 $t$의 입력 $x_t$를 처리한 뒤 은닉 상태 $h_t$를 만든다. 이 상태를 현재 출력에 사용할 뿐 아니라 다음 시점의 계산에도 넘긴다.

은닉 상태는 과거 입력을 그대로 저장한 목록이 아니다. 현재 입력과 직전 상태를 정해진 크기의 숫자 벡터로 압축한 결과다. 새 입력이 들어올 때마다 내용이 갱신되므로, 같은 값이라도 앞에 무엇이 왔는지에 따라 다른 상태가 만들어질 수 있다.

예를 들어 은닉 상태의 크기를 4로 정했다면 입력이 열 시점이든 백 시점이든 다음 시점으로 넘기는 값은 네 개다. 시퀀스가 길어져도 메모장 자체가 길어지는 구조는 아니다. 제한된 칸에 새 정보를 계속 섞으므로 무엇을 남기고 잃을지는 가중치와 학습 결과에 달려 있다. 여기서 “기억한다”는 표현은 과거 원본을 꺼내 볼 수 있다는 뜻이 아니라, 이후 계산에 영향을 줄 요약값을 전달한다는 뜻이다.

그림에서는 이해를 위해 입력과 상태를 숫자 하나로 둔다. 실제 RNN에서는 둘 다 벡터이고 가중치는 행렬이지만, “현재 입력과 이전 상태를 합쳐 새 상태를 만든다”는 원리는 같다.

## 2. 기호와 수식: 현재 입력에 이전 상태를 더한다

가장 단순한 RNN의 은닉 상태는 다음처럼 계산할 수 있다.

$$
h_t=\tanh(W_xx_t+W_hh_{t-1}+b)
$$

$W_x$는 현재 입력의 영향, $W_h$는 이전 상태의 영향을 조절하는 가중치다. $b$는 편향이고, $\tanh$는 계산 결과를 -1과 1 사이로 누르는 활성화함수다. 첫 시점에는 과거 상태가 없으므로 보통 $h_0=0$에서 시작한다.

중요한 점은 모든 시점에서 같은 $W_x$, $W_h$, $b$를 사용한다는 것이다. 입력 길이가 3에서 30으로 늘어도 시점마다 새 가중치를 만들지 않는다. 대신 이전 상태가 다음 계산에 계속 참여하면서 순서 정보를 전달한다.

계산 그림을 왼쪽에서 오른쪽으로 펼치면 같은 RNN 셀이 시점 수만큼 복사된 것처럼 보인다. 하지만 복사본마다 다른 매개변수를 가진 것이 아니다. 한 셀의 매개변수를 되풀이해 적용한 계산 그래프다. 그래서 각 시점에서 생긴 오차가 같은 가중치의 학습에 함께 영향을 준다.

## 3. 작은 손계산: 0을 넣어도 왜 상태가 남을까

$W_x=1$, $W_h=0.5$, $b=0$, $h_0=0$으로 두고 입력을 $[1,0,1]$ 순서로 넣어 보자. 첫 상태는 다음과 같다.

$$
h_1=\tanh(1\times1+0.5\times0)=\tanh(1)\approx0.7616
$$

둘째 입력은 0이지만 이전 상태가 더해진다.

$$
h_2=\tanh(1\times0+0.5\times0.7616)
\approx\tanh(0.3808)\approx0.3634
$$

따라서 현재 입력만 본다면 사라졌을 첫 값의 흔적이 남는다. 셋째 시점에는 새 입력 1과 이 흔적이 함께 들어간다.

$$
h_3=\tanh(1+0.5\times0.3634)\approx0.8280
$$

## 4. 실행 가능한 Python 실습

다음 코드는 외부 패키지 없이 위의 스칼라 RNN을 그대로 실행한다. 마지막에는 같은 세 값을 반대 순서로 넣어 최종 상태를 비교한다.

```python
import math


def run_rnn(sequence, w_x=1.0, w_h=0.5):
    h = 0.0
    states = []
    for x in sequence:
        h = math.tanh(w_x * x + w_h * h)
        states.append(h)
    return states


sequence = [1.0, 0.0, 1.0]
states = run_rnn(sequence)
for step, (x, h) in enumerate(zip(sequence, states), 1):
    print(f"t={step}, x={x:+.1f}, h={h:+.4f}")

for values in ([1.0, 0.0, -1.0], [-1.0, 0.0, 1.0]):
    print(f"{values} -> final h={run_rnn(values)[-1]:+.4f}")
```

실행 출력은 다음과 같다.

```text
t=1, x=+1.0, h=+0.7616
t=2, x=+0.0, h=+0.3634
t=3, x=+1.0, h=+0.8280
[1.0, 0.0, -1.0] -> final h=-0.6741
[-1.0, 0.0, 1.0] -> final h=+0.6741
```

## 5. 결과 해석: 값의 집합이 같아도 순서가 다르면 결과가 다르다

마지막 두 시퀀스에는 `-1, 0, 1`이 한 번씩 들어 있다. 그러나 `[1, 0, -1]`의 최종 상태는 -0.6741이고, 반대 순서의 최종 상태는 +0.6741이다. RNN이 각 입력을 독립적으로 처리하지 않고, 직전까지 누적된 상태 위에서 현재 입력을 계산하기 때문이다.

$W_h$를 0으로 바꾸면 이전 상태 항이 사라진다. 그러면 각 시점의 상태는 현재 입력만으로 정해져 순서의 흔적을 전달하지 못한다. 반대로 $W_h$의 크기가 커지면 과거 상태의 영향이 더 강해지지만, 오래된 정보를 무조건 정확히 보존한다는 뜻은 아니다.

또한 최종 상태 하나가 시퀀스의 모든 세부 정보를 보존한다고 볼 수 없다. 이번처럼 상태가 숫자 하나라면 여러 과거 입력이 하나의 값에 섞인다. 실제 모델은 은닉 상태의 차원을 늘릴 수 있지만, 상태 크기와 입력 길이가 모델의 이해력을 자동으로 보장하지는 않는다. 어떤 정보를 남겨야 하는지는 데이터와 학습 목표가 정한다.

기본 RNN은 긴 시퀀스를 학습할 때 여러 시점에 걸친 미분의 곱 때문에 기울기 소실이나 폭발을 겪을 수 있다. 학습 과정에서는 [역전파와 연쇄법칙으로 구한 기울기]({{ '/posts/deep-learning-backpropagation-chain-rule/' | relative_url }})가 시간 방향으로도 이어진다. 이번 예제는 학습 전의 순전파만 분리해 은닉 상태의 역할을 확인한 것이다.

따라서 이 예제의 최종 상태 차이는 “RNN이 순서를 사용할 통로가 있다”는 증거이지, 긴 문맥을 잘 학습했다는 성능 증거는 아니다. 순전파 식과 학습 가능성, 실제 학습 성능은 구분해서 해석해야 한다.

실제 분류 모델이라면 은닉 상태에서 예측값을 만들고 [손실함수로 정답과의 차이]({{ '/posts/deep-learning-loss-functions-mse-cross-entropy/' | relative_url }})를 계산한다. 이후 공유 가중치 $W_x$와 $W_h$가 여러 시점에서 받은 기울기를 모아 갱신된다.

## 6. 직접 바꿔 보는 연습

먼저 `w_h=0.0`으로 바꾸고 둘째 상태가 정확히 0이 되는지 확인한다. 다음으로 `w_h=0.9`를 넣어 첫 입력의 흔적이 둘째 상태에 얼마나 더 남는지 비교한다.

그다음 `[1.0, 0.0, 0.0, 0.0]`을 실행해 입력이 사라진 뒤 상태가 어떻게 줄어드는지 기록한다. 마지막으로 `math.tanh`를 항등함수처럼 제거했을 때 상태 범위가 더 이상 -1과 1 사이로 제한되지 않는다는 점도 확인해 본다.

## 핵심 요약

- RNN은 현재 입력 $x_t$와 이전 은닉 상태 $h_{t-1}$를 합쳐 새 상태 $h_t$를 만든다.
- 은닉 상태는 과거 입력의 목록이 아니라, 현재 시점까지의 정보를 고정된 크기로 압축한 값이다.
- 모든 시점에 같은 가중치를 공유하므로 입력 길이가 늘어도 시점별 매개변수를 새로 만들지 않는다.
- 같은 값의 집합도 입력 순서가 바뀌면 은닉 상태의 계산 경로와 최종 결과가 달라진다.
- 기본 RNN은 긴 거리의 정보를 학습할 때 기울기 소실·폭발 문제가 생길 수 있다.
