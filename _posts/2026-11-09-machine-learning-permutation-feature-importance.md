> **이번 글의 목표:** 특성 선택이 필요한 이유를 이해하고, 검증 자료의 한 열을 섞어 점수 감소량으로 순열 중요도를 계산한다.

이미 학습된 분류 모델을 검증 자료 8개에 적용하니 정확도가 **1.000**이었다. 공부 시간만 여러 번 섞으면 평균 정확도가 **0.487**로 떨어져 순열 중요도는 **0.512**가 된다. 출석 횟수는 **0.287**, 좌석 번호는 **0.000**이다. 모델이 어떤 특성의 질서에 의존했는지를 점수 변화로 읽은 결과다.

앞 글에서 [불균형 분류의 지표가 질문에 따라 달라지는 이유]({{ '/posts/machine-learning-imbalanced-classification-precision-recall/' | relative_url }})를 확인했다. 순열 중요도도 같은 원칙을 따른다. 정확도·정밀도·재현율 가운데 어떤 점수를 쓰느냐에 따라 “중요하다”의 뜻이 달라진다.

## 1. 직관: 필요한 열의 연결을 끊어 보기

특성은 모델이 예측할 때 받는 입력 열이다. 특성이 많다고 항상 좋은 것은 아니다. 예측과 관계없는 열은 계산과 설명을 늘리고, 학습 자료의 우연한 패턴을 외울 기회도 만든다. **특성 선택(feature selection)**은 사용할 특성의 일부를 고르는 과정이다.

그렇다고 열을 하나 지우고 모델을 매번 처음부터 학습해야만 영향력을 살펴볼 수 있는 것은 아니다. **순열 중요도(permutation importance)**는 학습을 마친 모델과 평가 자료를 그대로 두고, 한 특성 열의 값만 행 사이에서 섞는다. 값의 종류와 개수는 유지되지만 그 값이 원래 대상과 맺던 연결은 끊어진다.

섞은 뒤 점수가 크게 떨어지면 이 모델이 그 특성의 원래 배열에 많이 의존했다고 해석한다. 점수가 거의 그대로라면 이 평가 자료와 점수에서 모델의 의존도가 작았다는 뜻이다. 특성 자체의 보편적 가치나 원인 효과를 증명하는 값은 아니다.

## 2. 기호와 수식: 기준 점수에서 섞은 점수를 뺀다

학습된 모델을 $m$, 검증 자료를 $D$, 기준 점수를 $s$라고 하자. 특성 $j$만 $K$번 다르게 섞어 얻은 점수를 $s_{k,j}$라 하면 중요도 $i_j$는 다음과 같다.

$$
i_j=s-\frac{1}{K}\sum_{k=1}^{K}s_{k,j}
$$

값이 클수록 그 특성을 섞었을 때 점수가 많이 나빠졌다는 뜻이다. 0에 가깝다면 평균 점수 변화가 거의 없고, 음수라면 섞은 뒤 오히려 점수가 좋아진 경우다. 표본이 작으면 한 번의 섞기 결과가 우연에 흔들리므로 여러 번 반복해 평균과 흩어짐을 함께 보는 편이 안전하다.

## 3. 작은 손계산: 점수 네 개를 평균 내기

실습의 난수 시작값 7에서 공부 시간을 처음 네 번 섞은 정확도는 `0.500, 0.125, 0.625, 0.500`이고 기준 정확도는 1.000이다. 섞은 점수의 평균은 다음과 같다.

$$
\frac{0.500+0.125+0.625+0.500}{4}=0.4375
$$

따라서 이 네 번에 대한 순열 중요도는 $1.000-0.4375=0.5625$다. 다른 무작위 순열을 사용하면 값은 달라질 수 있다. 그래서 아래 실습은 난수 시작값을 고정하고 열마다 10번 섞어 재현 가능한 평균을 구한다.

## 4. 실행 가능한 Python 실습

외부 패키지 없이 이미 학습되었다고 가정한 분류 규칙을 검증 자료에 적용한다. 모델은 공부 시간과 출석 횟수를 사용하고 좌석 번호는 사용하지 않는다. `random.Random(7)`로 순열을 고정한다.

```python
import random

X = [
    [1, 8, 12], [2, 6, 41], [3, 4, 7], [4, 3, 35],
    [1, 2, 18], [2, 7, 29], [3, 8, 5], [4, 5, 44],
]
y = [0, 0, 0, 1, 0, 1, 1, 1]
names = ["공부 시간", "출석 횟수", "좌석 번호"]

def predict(row):
    return int(2 * row[0] + row[1] >= 11)

def accuracy(rows):
    correct = sum(predict(row) == target for row, target in zip(rows, y))
    return correct / len(y)

baseline = accuracy(X)
rng = random.Random(7)
print(f"기준 정확도: {baseline:.3f}")

for feature, name in enumerate(names):
    scores = []
    for _ in range(10):
        shuffled = [row[:] for row in X]
        values = [row[feature] for row in X]
        rng.shuffle(values)
        for row, value in zip(shuffled, values):
            row[feature] = value
        scores.append(accuracy(shuffled))
    mean_score = sum(scores) / len(scores)
    print(f"{name}: 섞은 정확도={mean_score:.3f}, "
          f"중요도={baseline - mean_score:.3f}")
```

실행 출력은 다음과 같다.

```text
기준 정확도: 1.000
공부 시간: 섞은 정확도=0.487, 중요도=0.512
출석 횟수: 섞은 정확도=0.713, 중요도=0.287
좌석 번호: 섞은 정확도=1.000, 중요도=0.000
```

## 5. 결과 해석: 중요도 0은 삭제 명령이 아니다

공부 시간을 섞었을 때 정확도가 가장 많이 떨어졌으므로 이 모델은 검증 자료에서 공부 시간의 배열에 가장 많이 의존했다. 출석 횟수도 예측에 기여하지만 감소 폭은 더 작다. 좌석 번호는 `predict` 함수가 읽지 않으므로 아무리 섞어도 예측이 바뀌지 않는다.

이 결과만으로 좌석 번호를 무조건 삭제하면 안 된다. 먼저 모델의 기준 성능이 충분한지 확인해야 한다. 잘못 학습된 모델이 유용한 특성을 쓰지 못했다면 그 특성의 중요도도 낮게 나온다. 또한 서로 비슷한 정보를 가진 두 특성이 있으면 하나를 섞어도 다른 하나가 대신해 둘 다 낮게 보일 수 있다.

특성 선택의 판단은 중요도 표에서 끝나지 않는다. 낮은 특성을 제외한 새 입력 집합으로 모델을 다시 학습하고, 같은 검증 절차에서 성능과 흔들림을 비교해야 한다. 특성을 줄였는데 점수가 유지되면 더 단순한 입력으로 비슷한 예측을 얻은 것이다. 반대로 점수가 나빠지면 처음 중요도 계산이 그 특성의 역할을 충분히 드러내지 못했을 수 있으므로 제외 결정을 되돌린다. 특성 수가 줄었다는 사실 자체가 성능 향상을 보장하지는 않는다.

반복 결과의 분포도 단서가 된다. 평균 중요도가 같아도 열 번 모두 비슷하게 떨어진 특성과, 어떤 순열에서는 크게 떨어지고 다른 순열에서는 거의 변하지 않은 특성은 확실성이 다르다. 실제 도구가 평균과 표준편차를 함께 반환하는 이유다. 작은 검증 자료에서는 한두 행의 배치만 달라져도 점수가 크게 움직일 수 있으므로 반복 횟수만 늘리기보다 평가 자료의 크기와 대표성도 점검해야 한다.

순열 중요도는 모델에 내장된 고정 속성이 아니라 **모델·평가 자료·점수**의 조합에 대한 결과다. [학습·검증·테스트 자료의 역할]({{ '/posts/machine-learning-train-validation-test-split/' | relative_url }})에 따라 검증 자료에서 특성 선택 후보를 정하고 다시 학습·검증한 뒤, 테스트 자료는 마지막 비교에 남겨야 한다. 테스트 중요도를 보고 특성을 골랐다면 이미 테스트 자료를 선택 과정에 사용한 셈이다.

이 방법은 모델 종류와 무관하게 예측 점수만 다시 계산할 수 있으면 적용할 수 있다. 특히 [랜덤 포레스트가 여러 특성과 나무를 함께 사용하는 과정]({{ '/posts/machine-learning-random-forest-bagging/' | relative_url }})처럼 내부 판단을 한 줄로 읽기 어려운 모델을 점검할 때 유용하다. 다만 순열 중요도는 “이 특성이 결과의 원인이다”가 아니라 “이 모델의 점수가 이 특성의 배열에 얼마나 의존했는가”에 답한다.

평가 점수의 방향도 확인해야 한다. 이 글의 정확도처럼 클수록 좋은 점수는 기준 점수에서 섞은 점수를 빼면 된다. 오차처럼 작을수록 좋은 값을 직접 사용한다면 차이의 방향을 맞춰야 한다. 같은 모델이라도 불균형 분류에서 정확도를 쓰면 다수 클래스를 잘 맞히는 특성이 앞설 수 있고, 재현율을 쓰면 양성을 찾는 데 필요한 특성이 앞설 수 있다. 중요도 숫자는 선택한 질문과 분리해 읽을 수 없다.

## 6. 직접 바꿔 보는 연습

1. `range(10)`을 `range(50)`으로 바꾸고 중요도 평균이 얼마나 달라지는지 비교한다.
2. `accuracy` 대신 양성 클래스의 재현율을 계산해 세 중요도의 순서가 유지되는지 확인한다.
3. 좌석 번호를 모델 식에 작게 더한 뒤 중요도가 0에서 어떻게 바뀌는지 관찰한다.

## 핵심 요약

- 특성 선택은 모델에 넣을 입력 열의 일부를 고르는 과정이며, 순열 중요도는 선택 후보를 살피는 한 가지 모델 점검 도구다.
- 순열 중요도는 기준 점수에서 한 특성을 여러 번 섞은 점수의 평균을 뺀 값이다.
- 낮은 중요도는 자동 삭제 명령이 아니다. 기준 성능, 평가 점수, 상관된 특성, 자료 분리를 함께 확인해야 한다.
